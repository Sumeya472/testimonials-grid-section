# Frontend Mentor - Testimonials grid section

![Design preview for the Testimonials grid section coding challenge](./preview.jpg)

A responsive testimonials section built with **HTML5 and Tailwind CSS** as part of a [Frontend Mentor](https://www.frontendmentor.io/) challenge.

## Features

- Responsive layout for mobile, tablet, and desktop screens
- Five testimonial cards with different styles
- CSS Grid layout using Tailwind CSS utility classes
- Custom colors based on the provided style guide
- Google Fonts integration using Barlow Semi Condensed
- Profile images with rounded borders
- Decorative quotation mark
- Semantic HTML structure

## Built With

- HTML5
- Tailwind CSS
- Google Fonts
- Git and GitHub

## What I Learned

While building this project, I practiced:

- Creating responsive layouts with Tailwind CSS
- Using CSS Grid through Tailwind utility classes
- Understanding `grid-cols-*`, `col-span-*`, and `row-span-*`
- Centering content with Flexbox
- Controlling spacing with padding, margin, and gap utilities
- Applying custom colors with HSL values
- Positioning decorative elements using relative and absolute positioning
- Improving typography and matching a design reference

## Getting Started

To run this project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/Sumeya472/testimonials-grid-section.git
   ```

2. Open the project folder:

   ```bash
   cd testimonials-grid-section
   ```

3. Open `index.html` in your browser.
